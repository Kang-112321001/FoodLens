# W05 DOM 互動實作

## 功能名稱

食品名稱搜尋與結果篩選。

## Event

監聽搜尋表單的 `submit` 事件。使用者輸入食品名稱並按下搜尋後執行篩選，同時透過 `event.preventDefault()` 避免表單重新載入頁面。

## Function

`filterFoods(keyword)` 負責：

1. 移除關鍵字前後空白。
2. 比對食品卡片中的文字。
3. 顯示符合條件的食品。
4. 隱藏不符合條件的食品。
5. 更新搜尋結果筆數。
6. 沒有結果時顯示提示訊息。

## DOM 操作

- 使用 `querySelector()` 取得搜尋表單、輸入框及結果筆數。
- 使用 `querySelectorAll()` 取得所有食品卡片。
- 使用 `textContent` 更新結果筆數。
- 使用 `style.display` 顯示或隱藏食品卡片。
- 使用 `createElement()` 建立無搜尋結果的提示訊息。

## Expected UI

- 搜尋「豆漿」時只顯示無糖豆漿。
- 搜尋「餅乾」時只顯示原味蘇打餅乾。
- 搜尋「雞蛋」時只顯示蛋小白雞蛋干。
- 沒有符合資料時顯示「找不到符合條件的食品」。
- 空白搜尋時重新顯示所有食品。

## Constraints

- 目前只搜尋頁面上的三筆範例資料。
- 搜尋採部分文字比對。
- 空白關鍵字視為顯示全部資料。
- 正式資料庫搜尋將在後續以 Express API 與 SQLite 實作。

## 測試結果

| 測試輸入 | 預期結果 | 實際結果 |
|---|---|---|
| 豆漿 | 顯示 1 筆豆漿資料 | 通過 |
| 餅乾 | 顯示 1 筆餅乾資料 | 通過 |
| 雞蛋 | 顯示 1 筆雞蛋資料 | 通過 |
| 不存在的食品 | 顯示無結果提示 | 通過 |
| 空白 | 顯示全部 3 筆資料 | 通過 |

## AI 協作提示詞

請使用原生 JavaScript 為 FoodLens 實作食品名稱搜尋。使用者提交搜尋表單時，依關鍵字篩選 `.food-row`，更新結果筆數，空白搜尋顯示全部，沒有符合資料時顯示提示。不要重新載入頁面，也不要使用外部 JavaScript 套件。

## 自己的理解

這個功能透過表單事件取得使用者輸入，再呼叫篩選函式逐一檢查食品卡片。符合關鍵字的卡片保留，不符合的卡片隱藏，最後更新畫面上的結果筆數。這是 JavaScript 事件、函式與 DOM 操作的整合應用。
